# Helpdesk: система заявок техподдержки

Клиент-серверное приложение с REST API и авторизацией. Сотрудники создают заявки о проблемах с техникой и доступом и следят за статусом, сотрудники поддержки принимают заявки в работу, меняют статусы и отвечают в комментариях.

## Возможности

- Регистрация и вход по логину и паролю, сессия на JWT-токене.
- Две роли: **сотрудник** (видит и ведёт только свои заявки) и **поддержка** (видит все заявки, меняет статус и приоритет, назначает исполнителя).
- Заявки: тема, описание, приоритет (низкий, обычный, высокий), статусы «Новая», «В работе», «Решена», «Закрыта».
- Комментарии к заявкам, поиск по тексту, фильтр по статусу со счётчиками.
- Веб-интерфейс, адаптированный под телефон и компьютер (на широком экране список и заявка рядом).
- Демо-данные создаются при первом запуске.

## Стек

| Часть | Технологии |
|-------|------------|
| Сервер | Python 3, FastAPI, Uvicorn |
| База данных | SQLite через SQLAlchemy 2 |
| Авторизация | JWT (PyJWT), пароли хэшируются PBKDF2-SHA256 |
| Клиент | HTML, CSS и JavaScript без сборки и фреймворков |
| Тесты | pytest, httpx |

Проверено на Python 3.12 с FastAPI 0.165, SQLAlchemy 2.1, PyJWT 2.7 и 2.15.

## Запуск

Нужен Python 3.10 или новее.

**Windows** (в папке проекта открыть консоль):

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn src.main:app --reload
```

**macOS и Linux:**

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn src.main:app --reload
```

Открыть в браузере: <http://127.0.0.1:8000>. Интерактивная документация API: <http://127.0.0.1:8000/docs>.

Остановить сервер: `Ctrl+C`. Если порт 8000 занят, добавьте `--port 8001`.

### Демо-аккаунты

| Роль | Логин | Пароль |
|------|-------|--------|
| Сотрудник | `demo` | `demo123` |
| Поддержка | `agent` | `agent123` |

Новые пользователи, зарегистрированные через форму, всегда получают роль «сотрудник».

### Запуск с телефона в одной сети

Чтобы открыть приложение с телефона, запустите сервер так: `uvicorn src.main:app --host 0.0.0.0` и откройте в браузере телефона `http://<IP-адрес-компьютера>:8000`. Телефон и компьютер должны быть в одной Wi-Fi сети.

## Тесты

```
pip install -r requirements-dev.txt
pytest
```

Тесты используют отдельную базу в памяти и не трогают файл `helpdesk.db`. Покрыты регистрация, вход, права доступа, жизненный цикл заявки, комментарии, статистика и демо-данные (31 тест).

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `DATABASE_URL` | `sqlite:///./helpdesk.db` | Адрес базы данных |
| `SECRET_KEY` | тестовый ключ | Ключ подписи токенов. **Задайте свой при любом размещении в сети** |
| `TOKEN_TTL_MINUTES` | `720` | Срок жизни токена |
| `SEED_DEMO` | `1` | `0` отключает создание демо-данных |

## API

Все маршруты, кроме регистрации и входа, требуют заголовок `Authorization: Bearer <токен>`.

| Метод | Адрес | Описание |
|-------|-------|----------|
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход, возвращает токен |
| GET | `/api/auth/me` | Текущий пользователь |
| GET | `/api/tickets` | Список заявок (`?status=`, `?search=`) |
| GET | `/api/tickets/stats` | Количество заявок по статусам |
| POST | `/api/tickets` | Создать заявку |
| GET | `/api/tickets/{id}` | Заявка с комментариями |
| PATCH | `/api/tickets/{id}` | Изменить статус, приоритет, исполнителя |
| POST | `/api/tickets/{id}/comments` | Добавить комментарий |
| GET | `/api/health` | Проверка работы сервера |

Права на изменение заявки: поддержка меняет статус, приоритет и исполнителя; автор может только закрыть свою заявку или открыть её заново. В закрытой заявке комментарии недоступны.

## Ограничения

- База SQLite подходит для демонстрации и небольшой нагрузки; для продакшена нужна PostgreSQL или аналог.
- Токен хранится в `localStorage` браузера; для публичного размещения нужен HTTPS.
- Нет восстановления пароля, вложений к заявкам и уведомлений.
