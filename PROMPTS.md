# Дневник промптов

Ключевые запросы, которые определили проект. Полная хронология: [.agent/prompt-log.md](.agent/prompt-log.md).

## Промпт 1. Выбор типа проекта
**Запрос:** выбрать тип проекта из списка так, чтобы он с большей вероятностью получился без ошибок, без рискованных экспериментов.
**Результат:** клиент-серверное приложение с REST API и авторизацией: FastAPI, SQLite, JWT, веб-клиент без сборки, тесты на pytest. Тема: заявки техподдержки.
**Почему важно:** отказ от мобильной сборки (нет Android SDK) и от ML снизил риск, а проект остался в рамках пункта «клиент-серверное приложение с REST API и авторизацией».

## Промпт 2. Способ запуска
**Запрос:** как запустить приложение, если ПК нет. Затем: запуск только с ноутбука, на GitHub загрузить отдельно.
**Результат:** варианты Termux и бесплатного хостинга рассмотрены и отклонены (риск установки зависимостей на телефоне, SQLite стирается на бесплатном тарифе Render). Выбран локальный запуск на ноутбуке.
**Влияние на проект:** в проект добавлены демо-данные при первом запуске и инструкция запуска для Windows, macOS и Linux.

## Промпт 3. Сборка проекта
**Запрос:** «Начинай».
**Результат:** сервер (маршруты, сервисы, модели, JWT), веб-клиент, 31 автотест, документация. Проверка: тесты прошли, сценарии «регистрация, заявка, комментарий, закрытие, чужая заявка, неверный пароль» пройдены в браузере песочницы агента.
