# Ошибки агента и способы исправления

Записаны только ошибки, которые действительно произошли в этом диалоге.

## 1. Лишний маршрут-заглушка в `routers/tickets.py`
- **Что:** при написании файла агент добавил в конец ненужную функцию `_unused` с маршрутом `/agents/list`.
- **Как заметили:** агент сам при просмотре файла после записи, до запуска тестов.
- **Исправление:** фрагмент удалён скриптом, файл перечитан.

## 2. Фоновый сервер завершался между командами
- **Что:** первая проверка в браузере упала с `ERR_CONNECTION_REFUSED`: сервер, запущенный в фоне в предыдущем вызове, не пережил его завершения.
- **Исправление:** сервер и проверка запускаются в одной команде.

## 3. Неверный селектор в проверочном скрипте
- **Что:** клик по `text=Поддержка` попал в абзац «...и поддержка возьмёт её в работу», а не в кнопку, поэтому вход не выполнился. Сначала это выглядело как ошибка приложения.
- **Исправление:** селектор заменён на `get_by_role("button", name="Поддержка")`. Приложение при этом было исправно.

## 4. Неточность про Railway
- **Что:** в одном из ответов агент назвал Railway бесплатным хостингом.
- **Как заметили:** при проверке условий поиском выяснилось, что бесплатный кредит там $1 в месяц и хватает лишь на несколько часов работы.
- **Исправление:** в следующем ответе это уточнено, Railway не рекомендован.

## 5. Совет про загрузку архива на GitHub
- **Что:** агент ранее предложил загрузить архив через «Upload files» с телефона. Но GitHub не распаковывает zip, а мобильный выбор файлов обычно не сохраняет вложенные папки.
- **Исправление:** загружать распакованную папку целиком с ноутбука (перетаскиванием в окно браузера) или командами `git`. Инструкция в итоговом сообщении.

## Замечание, не являющееся ошибкой
- При запуске тестов появляется предупреждение библиотеки Starlette об устаревании `httpx` в `TestClient`. На работу тестов оно не влияет.
