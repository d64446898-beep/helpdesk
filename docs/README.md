# Материалы к проекту

Сюда добавляются файлы, которые нужно получить из работающего приложения:

- `screenshots/`: скриншоты экранов (вход, список заявок, заявка с комментариями, форма новой заявки, вид поддержки);
- `demo.mp4`: видео-демонстрация на 30-60 секунд (вход, создание заявки, смена статуса поддержкой, комментарий);
- `architecture.md`: схема компонентов (уже готова).
